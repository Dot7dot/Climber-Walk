# 霧林步道 Climber Walk

一個在瀏覽器中即時運行的山林散步小品：以 **原生 WebGPU** 繪製、所有內容皆由程式即時生成（無貼圖、無模型、無外部檔案），整個作品就是一個自給自足的 `index.html`。

▶ **線上遊玩：** https://dot7dot.github.io/Climber-Walk/ （需支援 WebGPU 的瀏覽器：Chrome / Edge 113+、Safari 18+）

## 場景元素（取材自實地照片）

- 紅檜／扁柏霧林：筆直紅褐樹幹、下段長滿苔蘚、垂掛的松蘿與下垂的扇形枝葉
- 長滿苔蘚的巨木、空心倒木、翻起根盤的倒木、苔蘚小丘與樹頭上的白色小蘑菇
- 蕨類地被、杜鵑灌叢、步道旁綁在枝條上的粉紅色路條
- 木棧道與木階梯、木柵欄、「保護苔蘚 請行走步道」告示牌
- 山頂的霧中草坡、扭曲的落葉闊葉樹、芒草、枯立木上的小鳥
- 層狀板岩峭壁、西側觀景台與雲海夕照、遠方層層山稜
- 日夜循環（黎明 → 晨霧 → 陰天 → 放晴 → 夕照 → 黃昏 → 入夜），霧氣隨時間飄移；夜裡可戴頭燈照路

## 操作

| 動作 | 方式 |
| --- | --- |
| 移動 | WASD／方向鍵（Shift 快走） |
| 走到某處 | 點擊地面 |
| 撿垃圾 | 點擊地上的垃圾，登山客會走過去彎腰撿起 |
| 視角 | 拖曳旋轉、滾輪（或雙指）縮放 |
| 裝備間 | 右側小人圖示或 `C` 鍵 |
| 快轉時間 | 點擊左上角的時間標籤或 `T` 鍵 |

## 紀錄與解鎖

遊戲會在瀏覽器 `localStorage` 記錄：**在山林中待了多久、走了多遠、撿了多少垃圾**。

| 部位 | 預設 | 時間解鎖 | 距離解鎖 | 垃圾兌換 |
| --- | --- | --- | --- | --- |
| 帽子 | 不戴帽、棒球帽 | 毛線帽（5 分鐘） | 登山頭盔（3 km） | 漁夫帽（♻3） |
| 上衣 | 排汗衫 | 刷毛外套（10 分鐘）、羽絨外套（25 分鐘） | | 輕便雨衣（♻6）、防水外套（♻10） |
| 褲子 | 登山短褲 | | 登山長褲（300 m） | 雨褲（♻5） |
| 鞋子 | 越野跑鞋 | | 登山靴（1 km） | 雨鞋（♻4） |
| 背包 | 不背包 | | 輕量攻頂包（500 m）、重裝大背包（5 km） | |
| 手持 | 空手 | | 登山杖（2 km） | 工作手套（♻2） |
| 臉部 | 無 | 頭巾（15 分鐘）、頭燈（30 分鐘） | | 太陽眼鏡（♻5） |

每個部件都可以換顏色。角色由各部件模組即時組裝。

## 技術

- 無任何引擎或函式庫：手寫 WebGPU 管線（WGSL 著色器）
- HDR + 4× MSAA（alpha-to-coverage 處理枝葉邊緣）、ACES 色調映射、高度霧與雲海、柔和霧氣粒子
- 程序化生成：地形、步道（含攤平與棧道）、樹木／蕨類／草叢網格、樹皮與苔蘚等材質皆在著色器中計算
- 效能：20 m 區塊視錐剔除、植被 LOD、依幀時間自動調整渲染解析度

## 開發

可讀原始碼在 `src/game.html`，建置出最小化的 `index.html`：

```sh
npm install
npm run build
```

目前建置大小：**約 91 KB（gzip 後約 36 KB）**。
