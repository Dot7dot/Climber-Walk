# 霧林步道 Climber Walk

一個在瀏覽器中即時運行的山林散步小品：以 **原生 WebGPU** 繪製、所有內容皆由程式即時生成（無貼圖、無模型、無外部檔案），整個作品就是一個自給自足的 `index.html`。

▶ **線上遊玩：** https://dot7dot.github.io/Climber-Walk/ （需支援 WebGPU 的瀏覽器：Chrome / Edge 113+、Safari 18+）

### 無法開啟？

- **三星網際網路（Samsung Internet）**、LINE／Facebook／Instagram 等 App 內建瀏覽器不支援 WebGPU：請用 Chrome 開啟（LINE 會自動改用外部瀏覽器，Android 上會提供「用 Chrome 開啟」按鈕）
- Android 版 Chrome 需要 Android 12 以上；部分手機只提供 WebGPU「相容模式」，遊戲會自動切換到相容的繪製路徑
- 若 Chrome 仍顯示無法使用顯示晶片，可在 `chrome://flags` 開啟「Unsafe WebGPU Support」後重新啟動 Chrome

## 場景元素（取材自實地照片）

- 紅檜／扁柏霧林：筆直紅褐樹幹、下段長滿苔蘚、垂掛的松蘿與下垂的扇形枝葉
- 長滿苔蘚的巨木、空心倒木、翻起根盤的倒木、苔蘚小丘與樹頭上的白色小蘑菇
- 蕨類地被、杜鵑灌叢、步道旁綁在枝條上的粉紅色路條
- 木棧道與木階梯、木柵欄、「保護苔蘚 請行走步道」告示牌
- 山頂的霧中草坡、扭曲的落葉闊葉樹、芒草、枯立木上的小鳥
- 層狀板岩峭壁、西側觀景台與雲海夕照、遠方層層山稜
- 日夜循環（黎明 → 晨霧 → 陰天 → 放晴 → 夕照 → 黃昏 → 入夜），霧氣隨時間飄移；夜裡可戴頭燈照路

## 太平山圖鑑與相機

山林裡會偶爾出現太平山的真實物種（物種資料取自 [Creature-Collection-Guy-CCG](https://github.com/Dot7dot/Creature-Collection-Guy-CCG) 的太平山生物圖鑑），共 **270 種動物與昆蟲**：鳥類、哺乳類、爬蟲類、兩棲類、蝴蝶、蛾、甲蟲、蜻蜓、蟬、蜂、螳螂與蜘蛛。

- 同一時間只會出現少數幾隻，而且牠們很容易受驚逃跑：慢慢靠近、在相機模式中潛行，跑步會嚇跑牠們
- 出現機率依 iNaturalist 在太平山的觀察筆數、官方特色物種、目前月份的活躍度決定；貓頭鷹、鼯鼠、蝙蝠、白鼻心與多數蛾類只在夜晚出現（戴著頭燈時，蛾會繞著燈飛）
- 附近有生物時，畫面下方會出現「聽到鳥鳴聲⋯⋯」之類的提示與方向箭頭
- 按 `F` 或右側 📷 進入相機：拖曳瞄準、滾輪／＋− 變焦（1×–6×），`空白鍵`或點擊拍照。生物需要在取景框內、夠大、沒有被樹幹或地形擋住才算拍到；拍得越大越清楚，評價 ★ 越高
- 拍到的物種會自動收錄進 **太平山圖鑑**（`G` 或右側 📖）：顯示你親手拍的照片、學名、科名、特有／保育等級、太平山各月觀察筆數、首次記錄時間與最佳評價；未拍到的物種只會顯示類群與活動時間作為提示
- 每個物種都是依身體構造（鳴禽、雉類、猛禽、貓頭鷹、鷺、鹿與山豬、獼猴、松鼠、鼯鼠、蝙蝠、蛇、蜥蜴、蛙、蜘蛛、蝴蝶、蛾、蜻蜓、甲蟲、蟬、蜂、螳螂⋯⋯）與配色即時生成的 3D 模型

更新物種資料：`python3 tools/gen_species.py <Creature-Collection-Guy-CCG>/guide/species.json`（只嵌入名稱、分類、保育等級與觀察統計等事實資料，不含原圖鑑的照片與文字）。

## 技術

- 無任何引擎或函式庫：手寫 WebGPU 管線（WGSL 著色器）
- HDR + 4× MSAA（alpha-to-coverage 處理枝葉邊緣）、ACES 色調映射、高度霧與雲海、柔和霧氣粒子
- 程序化生成：地形、步道（含攤平與棧道）、樹木／蕨類／草叢網格、樹皮與苔蘚等材質皆在著色器中計算
- 效能：20 m 區塊視錐剔除、植被 LOD、依幀時間自動調整渲染解析度

## 開發

可讀原始碼在 `src/game.html`，建置出最小化的 `index.html`：

```sh
npm install
npm run build
```

目前建置大小：**約 156 KB（gzip 後約 64 KB）**，其中約 26 KB 為 270 種生物的資料表。
